# Original PBR downloads

The 23 required ambientCG 2K PNGs are preserved here locally, outside runtime resources.
The `ice/` directory additionally preserves five original Ice 0002 maps.
The six unused DirectX normal duplicates were removed; the packer uses OpenGL normals.
They are ignored to avoid duplicating the originals and their packed derivatives in Git.
Re-download links, SHA-256 fingerprints, encoding, and the reproducible JDK-only
packing command are in [the material documentation](../../tools/materials/README.md).

No client or ordinary build task reads this directory.
