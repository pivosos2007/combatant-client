Player-model adaptation of the local native Spectrum 2 kit in src/main/resources/assets/combatant/ui/api/kits/adobe/spectrum2.
Foundation, Tabs, Button and ActionButton retain the source component geometry and states.
Names are scoped to avoid duplicate declarations in the UI script import flattener.
Onest uses the client typography; every used palette role is supplied by the active Combatant theme.
This is Combatant implementation code, not upstream Adobe code.
